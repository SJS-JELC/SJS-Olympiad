# Fixed public product geometry

These are the original generated RDKit 2025.09.1 SVG, atom-label coordinates and provenance for methanal and the approved nine-carbon ozonolysis product. They contain no student answer graphs. The provenance hashes verify both inputs and the unchanged product-source JSON.

`python scripts/generate-u5p7-products.py` uses Python standard library only to extend C–C/C–O vectors by 1.45 while leaving every C–H vector and all connectivity unchanged. `--check` reproduces the checked-in presentation. This pass does not claim to run RDKit.

Where pinned RDKit is installed, `--refresh-rdkit-base` explicitly regenerates these base inputs before the same extension. RDKit was unavailable in the environment used for this update. Retain these inputs; generated output alone cannot reproduce the geometry transformation.
