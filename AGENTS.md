# AGENTS.md

## Scope

This folder is an independent React, TypeScript and Vite application. It supersedes the inherited Power Apps manual-paste workflow here: do not create appCodex exports or edit original Power Apps files. The parent Olympiad folder and the separate Masters of Chemistry project are read-only references. Do not import personal/team data.

There are 33 registered theory questions: L5/L6/U6 slots 1–9 and U5 slots 2, 3, 5, 6, 7, 8, plus practical protocols for L5/L6/U6. Each named event fixes its year. Invalid questions and year mismatches remain unavailable. U5 has no practical.

Teacher-only confirmed deletion permanently removes draft team records and active teams without submitted activity; active teams with any submitted activity (including wrong attempts/timed runs) become excluded retained tombstones with reserved names. Both outcomes fence ownership before cleanup. Permanent cleanup uses conditional transactional chunks and minimal deletion receipts/fences to prevent retries, stale sessions or bootstrap resurrection; never classify activity from score alone. Completed events are read-only. Logout never releases claims. Bootstrap migration must preserve the three legacy L6 teams and L6P8 outcomes exactly once unless explicitly deleted through these guarded tools. Never overwrite saved settings or results on startup. ## Security contracts

Use exactly NOT_STARTED, ACTIVE and LOCKED. Keep one CompetitionSecurityProvider and one OlympiadBackground at the root. Query navigation uses history without reloading, preserving fullscreen, provider state and attempts.

- Initialize authentication before exposing protected content. Fresh page initialization uses session?restore=1: competitor role sessions are revoked and their cookie expires, returning to the access-code screen and team selection. Teacher role sessions are also revoked. Render the access forms immediately; serialize login after startup cleanup. Teacher login opens Settings. Cookies are session-only. Never use browser-persistent authentication or answer flags.
- Teachers may preview without fullscreen or a team, including outside theory times. Competitors may claim and enter fullscreen before theory starts, then see a countdown. Actual theory questions require the theory window; practical uses its independent window. Both require a valid event/team binding, server ACTIVE state and committed local fullscreen. Theory closing unmounts question content without manufacturing a breach, releasing a claim or resetting results/cooldowns; remaining practical time does not authorize theory writes. Restoration, transitions, failed verification and LOCKED synchronously unmount actual question content.
- While ACTIVE, hidden document, blur and fullscreen exit synchronously lock without awaiting persistence.
- Entry requires explicit GO and successful fullscreen. Recovery verifies the current teacher code on the server and issues a short-lived single-use grant. Explicit Resume enters fullscreen and consumes the bound grant without escalating the competitor's role; failed work keeps content gated. Never restore a hardcoded frontend PIN.
- Revalidate asynchronous entry/unlock work; stale/interrupted attempts cannot activate content.
- The server owns session, role, event, claim and recovery state. Keep local diagnostic events free of content/codes and local state restrictive only. External/cross-tab notifications can lock but never activate/unlock. Failed server persistence keeps content gated; do not recreate a parallel localStorage authority.
- LOCKED retains the inert, dimmed/blurred non-sensitive route shell beneath the root BreachModal. Keep its trapped focus, masked PIN field, in-dialog errors and exact COMPETITION MODE BREACHED heading. Escape/outside clicks/navigation cannot dismiss it.
- Report breaches with a security epoch and idempotency ID. Delayed old reports cannot relock a recovered epoch. Release invalidates recovery and stale submissions. Refresh/reopening signs competitors out without releasing team claims or deleting checked results; a teacher must allow reselection before that reserved team can be claimed again. Remove periodic session polling and navigation/save preflights. Each protected endpoint still verifies authentication, event time, ownership and security generation. Known deadlines gate locally; remote staff changes are detected on the next authorized request. In-page interruptions still require teacher recovery.
- Keep diagnostics free of sensitive data/question content. Prepare the looping breach alarm in the entry gesture; stop on successful recovery or leaving the authenticated session. Audio delivery remains browser-dependent.

Shared codes provide the requested access control, not individual staff identity. Browser events cannot guarantee device lockdown, reliable delivery or independently prove fullscreen to the server. Public presentation downloads are accepted; protected API operations still require the server role and session checks.

Teacher question screens hide routine Saved/preview/award/Teacher Mode footers without replacing them, while preserving pending saves, failures and retry controls; competitor status and teacher badges elsewhere stay unchanged. Teacher marking remains unscored. scripts/generate-completion-eagle.mjs reproduces its source-hashed 32×18 silhouette from retained original artwork; no reference-image asset is shipped.
