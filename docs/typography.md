# Typography

All live text uses six roles defined in src/typography.css. Font declarations stay in that file; components may set --text-size and --text-leading for geometry.

CompletionStamp uses Display/04b_19 in SVG user coordinates for the original server completion time and COMPLETE word. Its solid red outline/eagle and transparent interior are vector geometry, with no random holes or dither; reduced motion keeps the imprint static. This shared overlay does not introduce another typography role.

| Role/class | Typeface and treatment | Use |
| --- | --- | --- |
| Display / type-display | 04b_19, pale face, grey inset, downward shadow | Challenge headings |
| Outlined display / type-outlined | 04b_19, white face, black outline, #303030 downward shadow | Score label |
| Heading / type-heading | Heavier Tilt Neon | Question titles and section headings |
| Body / type-body | Regular Tilt Neon | Prompts and numeric text |
| Label / type-label | Heavier Tilt Neon | Controls, fields, legends |
| Caption / type-caption | Smaller Tilt Neon | Supporting information |

Use OlympiadHeading for display treatments, QuestionHeading for problem number/title, and the shared Score component for scores. Tilt Neon has one regular face; bold is browser-synthesised. text-small, text-heading-small, text-large and text-tabular reuse the same roles. Viewport-relative geometry keeps graphical chrome proportional; body text retains readable minimum sizes.

```tsx
<OlympiadHeading lines={['Theoretical', 'Challenge']} />
<OlympiadHeading lines={['Score']} as="span" variant="score" />
```

The outlined variant uses a 3.4-unit SVG outline and a sharp #303030 shadow offset zero horizontally and three pixels down. It has no inset. Each component owns a unique filter ID. The default display variant retains its inset treatment. Do not copy filters/font rules into individual screens.

Score digits use Body, with two zero-padded flip cards and one accessible announcement. The flip behavior is retained. Ordinary buttons use shared dark-grey/white styling; bespoke Challenge/Check artwork remains distinct. IllustratedActionButton supplies the reusable Enter Laboratory/Run treatment without adding submission or cooldown behavior.

Use height-relative shared text tokens without desktop maximum font ceilings. Primary targets are1920×1080 and2560×1440, with existing smaller landscape ratios preserved. ScientificDiagram uses Body for atom labels/angles and Caption for explanatory labels; its user-coordinate text scales with its SVG viewport, not an extra viewport-font multiplier. Preserve source chemical geometry. L6P5 derivatives are regenerated by scripts/create-newman-diagrams.mjs; P7 products by scripts/generate-u5p7-products.py with retained source/provenance. Main logo lettering remains artwork.

`npm run check:typography` rejects font declarations outside typography.css and unknown named type-* styles; the production build runs this gate. Fonts are locally served; preserve their attribution, notices and licensing limitations.
