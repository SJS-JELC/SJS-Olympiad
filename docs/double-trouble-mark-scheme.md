# U5P7 Double Trouble

Two points, 20-second cooldown. Source: user-approved `research/Provisional Future Problems/Double Trouble.md`.

| Degree of unsaturation | Accepted group |
| --- | --- |
| 0 | C₂H₆, C₁₀H₂₂O, C₄H₁₁N |
| 1 | C₄H₈, C₅H₁₀, C₂H₅N |
| 2 | C₃H₄O, C₂H₂O, C₅₀H₉₈ |

DBE = (2C + 2 + N - H)/2 for the ordinary neutral closed-shell formulae supplied; oxygen does not affect it. This describes the combined rings/multiple bonds, not a unique functional group or number of double bonds.

Accept all within-group and between-group permutations; reject duplicates, missing/unknown formulae and mixed partitions. Like the existing grouping questions, blank/incomplete checks do nothing. A complete wrong partition starts the fixed cooldown; reset clears local selection without removing it. Completion awards once and freezes all controls. Group selections stay in page memory only. The private key never ships to the browser.
